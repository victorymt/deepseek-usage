# DeepSeek 全量 Token 用量统计

这是一个运行在 `https://platform.deepseek.com/usage` 的油猴脚本，用来统计超过网页“最近 30 天”限制的历史用量。

## 安装

1. 打开 Tampermonkey 或 Violentmonkey 的管理面板。
2. 导入 [`deepseek-total-usage.user.js`](./deepseek-total-usage.user.js)。
3. 登录 DeepSeek 开放平台并打开 Usage 页面。

页面右下角会出现“总用量”按钮。弹窗包含两个视图：

- **总览**：默认统计 `2023-01-01` 至当天，也可以修改起止日期。
- **Token 日历**：选择月份后查看当月总量和每日 Token；点击日期可查看当天的输入、输出、请求数和缓存命中率。

## 统计口径

脚本调用页面自身使用的接口：

- `/api/v0/usage/by_api_key/amount`
- `/api/v0/usage/by_api_key/cost`

接口单次查询的时间范围有限，因此脚本把日期范围切成连续的 30 天窗口，再汇总请求数、缓存命中输入、缓存未命中输入、输出 Token 和费用。

总 Token 的计算方式为：

```text
缓存命中输入 + 缓存未命中输入 + 输出
```

脚本只使用当前页面的登录会话发起同源请求，不保存或显示登录令牌，也不会读取、记录或导出接口返回的 API Key 身份字段。

## 持久缓存

查询结果会按账号和时间段缓存在 DeepSeek 平台域名的 `localStorage` 中：

- 已结束的历史月份永久复用，不再重复请求。
- 当前月缓存有效期为 5 分钟，过期后只刷新当前月。
- 当前周和当天的数据从当前月的每日聚合记录中计算，不产生额外请求。
- 总览和 Token 日历共用缓存；先打开任一视图，另一个视图会直接复用结果。

缓存只包含请求数、Token、模型、日期和费用等聚合数字。账号 ID 仅用于生成本地缓存命名空间的哈希，不会保存登录令牌或 API Key 信息。清除该站点的浏览器数据即可删除缓存。
